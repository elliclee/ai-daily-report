## 1) JSON 输出字段格式（最高优先级，违反即校验失败）

每条 item（headlines / sections 内的条目）的 **唯一合法结构** 如下：
```json
{
  "title": "新闻标题",
  "time": "2026-02-25",
  "what": "发生了什么（1-2 句事实描述）",
  "why": "为什么重要（1-2 句影响分析）",
  "sources": [
    {"name": "来源名称", "url": "https://..."}
  ]
}
```
⛔ 禁止使用以下旧字段名（校验脚本会直接报错）：
  - `source`（应为 `sources` 数组）
  - `url`（应嵌套在 sources 内）
  - `published`（应为 `time`）
  - `summary`（应拆分为 `what` + `why`）
  - `category`（由 section key 隐含，无需此字段）

## 2.5) 时间验证（新增 - 最高优先级）

⚠️ **关键教训**：36kr 文章 https://www.36kr.com/p/3680115686895237 实际发布于 2026-02-12，但被误判为 2026-03-05

**所有新闻必须执行时间验证**：

1. **抓取原页面获取真实时间**：
   - 对每个新闻 URL 执行 `web_fetch` 或 `curl` 抓取原页面
   - 提取真实的发布时间戳（HTML meta、JSON-LD、或页面内嵌的时间字段）
   - 示例：36kr 的时间戳在 `publishTime` 字段（毫秒级 Unix 时间戳）

2. **时间提取方法**（按优先级）：
   - `<meta property="article:published_time" content="2026-03-05">`
   - `<script type="application/ld+json">` 中的 `datePublished`
   - 页面 API 返回的 JSON 中的 `publishTime` / `published_at`
   - HTTP 响应头 `Last-Modified`（仅作参考）

3. **严格过滤**（零容忍）：
   - ⛔ 只接受明确 ≤48h 的新闻
   - ⛔ 时间无法确认的 → 直接丢弃，不得入报
   - ⛔ 禁止用"搜索发现时间"推断"发布时间"
   - ⛔ 禁止用文章内容中的时间词（如"今天"、"昨日"）推断实际发布时间

4. **记录所有被剔除的条目**（在 self_check.rejected_entries）：

## 5) headlines 与 sections 的关系（禁止重复）

⛔ headlines 的 3-12 条新闻 **禁止** 与 sections 内的条目使用完全相同的 title
- headlines 是「当天最重要的新闻总结/综述视角」
- sections 是「按分类的详细报道」
- 允许同一事件同时出现在 headlines 和 sections，但 title 和 what/why 的措辞必须不同
  - headlines：侧重宏观影响和意义
  - sections：侧重技术细节和事实

## 6) x_highlights 来源约束与处理

**来源约束：**
- x_highlights 中的 url 字段必须是 x.com 或 twitter.com 链接
- ⛔ 非 X 来源（如新闻网站、博客、官方公告页）不得放入 x_highlights
- 非 X 来源的精彩引用应放入对应 section 条目的 sources 数组
- 若 bird 不可用导致无法获取真实推文，x_highlights 可以为空数组 []
  - 此时必须在 self_check.bird_status 说明原因

**内容处理（必须执行）：**
对于每条选中的 X 推文，必须：
1. **翻译**：将英文内容翻译成流畅的中文
2. **总结**：用 1-2 句话概括核心观点（比翻译更精炼）
3. **保留链接**：附上原贴入口 url

**输出格式：**
```json
{
  "author": "原文作者名",
  "handle": "@用户名",
  "text": "中文总结（1-2句话，概括核心观点）",
  "url": "https://x.com/...",
  "likes": 1234,
  "reposts": 567,
  "replies": 89
}
```

**示例转换：**
- 原文："Nvidia's Jensen Huang says markets 'got it wrong' on AI threat to software companies"
- 处理："英伟达CEO黄仁勋表示，市场对AI威胁软件公司的判断'错了'，AI将扩大软件市场而非摧毁"
- 链接：https://x.com/CNBC/status/...
